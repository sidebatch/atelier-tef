# TEF Atelier

TEF Canada 대비 어휘 · 리딩 학습 아틀리에.
A2·B1 500개 어휘 + A1·A2 1,466개 어휘 + B1·B2 1,401개 어휘 + B2 336개 어휘 + 관용 표현 305개, 총 4,008개를 복습하는 단일 페이지 앱입니다.

## 바로 실행

**[TEF Atelier 열기](https://sidebatch.github.io/atelier-tef/)**

**[CE 리딩 문제 풀기](https://sidebatch.github.io/atelier-tef/ce.html)**

**[사이클 학습](https://sidebatch.github.io/atelier-tef/cycle.html)** — 블록(기본 20개) 단위 반복 학습: 1회차 → 같은 블록 섞어서 2회차 → 틀린 것만 → 다음 블록, 3블록마다 누적 복습. 진도는 기존 단어장과 분리 저장(`tef-cycle-v1`).

## 단어장 선택

- A2·B1 단어 (500장): 원래 앱 그대로
- A1·A2 단어 (1,466장): 프랑스어 + 한국어(기본) + 영어
- B1·B2 단어 (1,401장): 시험 대비 신규 단어
- B2 단어 (336장): 프랑스어 + 한국어(기본) + 영어
- 관용 표현 (305장): 프랑스어 + 한국어(기본) + 영어, 220개에 예문 포함
- 전체 (4,008장)
- 진행 기록과 큐는 단어장별로 따로 저장됩니다. 세션(25개씩)도 단어장별로 나뉩니다.

## 리딩(ce.html)

- 문제별 🔊 지문 듣기, 문단별 🔊 듣기(문단 MP3 52개 내장)
- 단어 1탭=🔴 표시, 2연속탭=뜻 보기
- 🔤 보기 해석으로 선택지 해석 공부, 📖 해석 보기로 지문 해석

## 사용법

`index.html`을 브라우저로 열면 됩니다. 진행 상황은 해당 브라우저에 자동 저장됩니다.

- 기본: 프랑스어 → 한국어
- 방향 전환: 한국어 → 프랑스어 → **직접 쓰기(한국어 보고 프랑스어 입력)**
  - 직접 쓰기는 자동 채점: 대소문자·앞뒤 공백 무시, 악센트 없이 써도 정답 처리
  - 핵심 단어만 맞으면 정답: 관사(`l'`), 재귀대명사(`s'`), 끝 전치사(`de`), `+inf` 표기 없이 써도 인정 (정확한 형태를 함께 표시)
  - `d'ailleurs`·`du reste` 같은 고정 표현은 그대로 써야 정답
  - `/` 복수 정답 모두 인정, `모름` 버튼으로 패스 가능, Enter 키로 확인
- X: 전체/25개 세션에서는 10장 뒤, 오답만 모드에서는 3장 뒤에 재출제
- O: 연속 3회 정답이면 완료
- 프랑스 표준 발음 파일 836개 내장(A2·B1 500개 + B2 336개, 모바일 기기 음성 설치 불필요)

## 자동 점검 (배포 전 필수)

뭘 고치든 푸시하기 전에 먼저 돌리고, 전부 PASS일 때만 배포합니다.

```
cd tests && npm install   # 처음 한 번만
node tests/run-tests.js
```
